BBDown 软件停更下架通知

分类：通知公告发布时间：2026-08-19总阅读量：113

因仓库归档停更，该软件准备下载撤销

因上游 GitHub 仓库中，该项目已经停止更新并归档，遂考虑将该软件从本站删除。

非常感谢开发者提供的非常优秀好用的 哔哩哔哩 视频下载工具。但是该项目已于 2026年5月14日 归档，不再更新维护。

考虑到此类软件，需要实时跟进官方的 API 接口解析等，所以停止维护后将有很大概率会失效。所以本站决定将会撤下该软件，如果有需要类似 哔哩哔哩 视频下载的用户，可暂时使用猫抓、Downlink、NeatDM 等浏览器媒体嗅探工具替代。

后续在找到类似功能的软件后，评估通过后将上架本站。欢迎各位用户投稿！
